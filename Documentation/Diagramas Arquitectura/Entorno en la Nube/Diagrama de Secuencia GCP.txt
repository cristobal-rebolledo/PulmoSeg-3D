sequenceDiagram

    participant FE as Frontend
    participant CR as Cloud Run
    participant DB as Cloud SQL
    participant GCS as Cloud Storage

    CR->>GCS: Sube máscara (mask.nii.gz)
    CR->>DB: Actualiza estado → COMPLETED

        FE->>CR: GET /status/job_id
        CR->>DB: Consulta estado
